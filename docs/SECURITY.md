# Security Policy

## Supported Versions

Only the latest release of Flux is actively maintained. Update to the most recent version to receive security fixes.

| Version | Supported |
| --- | --- |
| Latest | Yes |
| Older | No |

## Reporting a Vulnerability

If you find a security vulnerability in Flux, please report it privately rather than opening a public issue.

1. Email `iamgautamsuthar@gmail.com` with the details. Do not disclose the issue publicly first.
2. Include a description of the vulnerability, steps to reproduce it, the potential impact, and a suggested fix if you have one.
3. Expect a response within 48 hours. Vulnerabilities that pose a significant risk are aimed to be patched within 7 days.

## Security Best Practices

- Keep Flux and its dependencies up to date.
- Use trusted package sources and verify integrity where possible.
- Avoid running Flux with elevated privileges unless it is necessary.
- Review packages and their dependencies before adding them to a project.
- Keep credentials in environment variables rather than hardcoding them.

## Responsible Disclosure

Reports that follow responsible disclosure are appreciated, and contributors can be publicly credited on request.

Please get in touch by email before creating a public issue.
